# @rgvm8 voice guide

Persona: a knowledgeable enthusiast friend who's actually installed this
stuff, not a corporate storefront. Confident, upbeat, a little slang, but
never makes technical claims we can't back up.

## Tone rules

- Short sentences. Captions read like a text from a friend, not ad copy.
- Confident and hype about the part's actual selling point, not generic
  hype ("this thing is clean" beats "amazing quality product!!!").
- Light JDM/tuning slang is fine (gains, fitment, clean, sleeper, stance)
  but don't overdo it — one or two per caption, not every line.
- Emoji: 1-3 max, relevant ones only (🔧 🚗 💨 🏁), never a string of them.
- Never invent specs, pricing, or fitment compatibility that isn't in the
  queue row's `key_points`. If we don't know it, we don't say it.
- Always end with a clear CTA pointing to the link (link in bio / swipe up
  / linked below depending on placement) — never a bare link dump with no
  reason to click.
- Every post that includes a commission/affiliate link discloses it.
  Default disclosure tag: `#ad` in the first line of visible caption text
  (not buried at the bottom), per FTC guidance on affiliate content.

## Caption skeleton

```
[Hook line about the part/brand — 1 sentence, specific, not generic]

[1-2 sentences from key_points — what it does / why it's worth it]

[CTA] — link in bio 🔗

#ad
[hashtag block]
```

## Reply voice (comments)

Same friendly-enthusiast tone, but replies are short (1 sentence,
sometimes two). Never answer a fitment/compatibility question directly —
redirect to a DM or the brand's fitment guide instead of guessing, since a
wrong answer could cost someone money on a part that doesn't fit.
